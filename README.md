# Node.js Learning Repository

A collection of Node.js class exercises, code snippets, and small practice projects. The focus is on learning server-side JavaScript concepts one topic at a time.

## Topics

- Node.js runtime and process basics
- The event loop and asynchronous execution
- Promises and promise chaining
- Core modules and file operations
- Express and small API examples
- Class exercises and practical assignments

## Explore the code

Most examples are individual files or live in their own folders. Open a file to review the concept, then run it with Node.js if its dependencies and required input files are available.

For a folder that contains a `package.json`, run from that folder:

```bash
npm install
node app.js
```

Use the folder's own `scripts` in `package.json` where they are defined. There is no single application entry point for the entire repository.

## Setup

Install a current Node.js LTS release. Confirm the installation:

```bash
node --version
npm --version
```

## Status

This is a learning archive, not one unified application. Some exercises may be incomplete or require their original class context. The repository contains a previously committed `node_modules` directory under `classyargstask/`; reinstall dependencies locally rather than relying on committed packages.
